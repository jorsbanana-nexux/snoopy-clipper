LETAKKAN FONT TEKS THUMBNAIL PODCAST DI SINI (assets/fonts/)

Rantai font (thumbnail.py -> _font_candidates):
1. THUMB_FONT_FILE di .env   (paling diutamakan)
2. File .ttf/.otf pertama di folder ini (urut nama)  <- LETAKKAN Liberica.ttf DI SINI
3. Font sistem bold: Liberation Sans Bold (Docker) / DejaVu Sans Bold (Linux)

Catatan lisensi: font bebas-pakai-komersial (mis. dari Google Fonts) boleh
langsung ditaruh di sini. Font "personal use only" (mis. Liberica dari
1001fonts) HANYA boleh dipakai kalau kamu memegang lisensinya — tanggung
jawab pemilik repo, bukan dibundel oleh project.
